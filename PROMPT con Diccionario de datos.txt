### SECTION 4: DICCIONARIO DE DATOS, COLUMNAS Y FÓRMULAS OFICIALES DE NEGOCIO

#### 1. MÓDULO NPS (Net Promoter Score & Satisfacción)
* COLUMNAS DEL ARCHIVO: Periodo, mes, dia, Programa, PCRC, Proveedor, Skill, Id agente, TECNOLOGIA ACCESO HOGAR, Nombre VDN AUTO, Q meda, Q Res, Q sat, sat top2, sat botton, Res si, Promotores, Neutro, detractor, Q 0y1, Sat - Asesor, Predisposición, Conocimiento, Producto, Campañas2, Producto Unificado, Semana.
* DEFINICIONES DE MÉTRICAS:
  - Cantidad de Encuestas = [Q meda]
  - Cantidad de Detractores = [detractor] (Notas menores a 4)
  - Cantidad de Promotores = [Promotores] (Nota equivalente a 9)
  - Cantidad de Neutros = [Neutro] (Notas entre 4 y 8)
* FÓRMULAS OFICIALES:
  - % NPS = ([Promotores] - [detractor]) / [Q meda]
  - % Detractor = [detractor] / [Q meda]
  - % Promotor = [Promotores] / [Q meda]
  - % Resolución = [Res si] / [Q Res]

#### 2. MÓDULO TMO (Tiempos de Operación y Auxiliares)
* COLUMNAS DEL ARCHIVO: Periodo, NombreProveedor, dia, NombreLider, ApellidoNombre, logid, nombrepcrc, SKILL, nombreSkill, Q llamadas, Tiempo TT, Tiempo Staff, Tiempo Avail, Tiempo ACW in, Tiempo Hold, Tiempo Saliente, Tiempo Auxiliares, Baño, Problema Sistema, Refrigerio, Agenda, Capacitación, Coaching individual, Coaching Express, Re entrenamiento, Gestiones Out, tareas gremiales, Otros, descanso visual, Reimagina, Aux 24, Programa, Campaña.
* FÓRMULAS Y MÉTRICAS INTERMEDIAS:
  - Cantidad de Llamadas Validas = [Q llamadas]
  - Baño_Horas = [Baño] / 3600
  - Refri_Hora = [Refrigerio] / 3600
  - _Coaching_HS = ([Coaching Express] + [Coaching individual] + [Agenda] + [Reimagina]) / 3600
  - Tiempo hablado con cliente (_TT) = ([Tiempo TT] + [Tiempo Hold] + [Tiempo ACW in]) / [Q llamadas]
  - Tiempo saliente (_TSaliente) = [Tiempo Saliente] / [Q llamadas]
  - Tiempo de holdeo (_HOLD) = [Tiempo Hold] / [Q llamadas]
  - ACW o Tiempo después de llamada (_ACW) = [Tiempo ACW in] / [Q llamadas]
  - TMO o TMO TOTAL = _TT + _TSaliente + _ACW + _HOLD
  - _Horas_Disponible = ((TMO * [Q llamadas]) + [Tiempo Avail]) / 3600
  - % Baño = Baño_Horas / _Horas_Disponible
  - % Refri = Refri_Hora / _Horas_Disponible
  - % Coaching = _Coaching_HS / _Horas_Disponible
